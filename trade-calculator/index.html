Where the values come from

2027 first-round picks are valued by exact slot. Later rounds and 2028 picks are valued by tier, so add a tier once for each pick involved.

What the value adjustment does

Adding values at face value lets a pile of depth pieces match one star, and nobody makes that trade. With the adjustment on, each extra piece in a package counts for less: two 50-point players are treated like one 76-point player.

The side getting the tighter package shows the difference as a value adjustment. The adjustment is this calculator's own math and is not part of the FantasyPros chart. Turn it off to compare plain sums.
